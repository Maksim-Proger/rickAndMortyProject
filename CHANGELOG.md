## [3.3] - 2025-10-28
### Добавлено
- Реализована офлайн-поддержка: данные персонажей теперь кэшируются в локальной базе Room.
- При недоступности API приложение получает данные из локального хранилища.
- Добавлена фильтрация по имени, статусу и гендеру с комбинированным поиском (API + локальная база).
- Поддержка поиска по имени в реальном времени.
- Расширен `RepositoryApiImpl`: теперь `RemoteMediator` и фильтрация корректно работают совместно.
- Логика загрузки персонажей переработана с использованием `combine` и `flatMapLatest` во ViewModel.
- Добавлено визуальное обновление списка через `PullToRefreshBox`.

### Исправлено
- Исправлены ошибки при комбинированной пагинации с фильтрацией.
- Исправлено падение при отсутствии интернет-соединения при детальном просмотре персонажа.
- Устранены проблемы с дублированием данных при обновлении фильтра или поиска.
